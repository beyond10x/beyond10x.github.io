Agent stack

One owner per layer

Seven layers from products down to model providers. A layer depends only on the layers below it. Recorded in the organization's architecture decisions 0096 to 0101 (2026-10-20), 0105 and 0106 (2026-10-22).

Open the agent stack as an interactive page: the layers assemble as you scroll, a call travels down them, and every term links to its definition and repository.

Each term, the layer it names, and the repositories that own it.
TermLayerWhat it doesOwned by
Model callL0One turn in, one turn out: messages and tools in; text, tool calls and usage out. Owns provider wires, credential presentation, routes and cost; custody and OAuth2 refresh of a credential belong to Connectors.llm (GitHub), inference, llm-gateway
HarnessL1The agent loop: turns, prompt assembly, tool round trips, compaction, session and transcript, budgets. Claude Code and Codex are vendor harnesses; tools holds the tool contracts.harness (GitHub), tools
Meta-harnessL2Starts any harness behind one event stream and one command set, allows, denies or rewrites each tool call, and records every session as trace-ir/1.metaharness (GitHub)
Agent runtimeL3 · governed runtimeLoom; loom-sdk is its library. Opens a case on a protocol and lets a model act only through the actions the case admits at that moment. Calls llm for its own short decisions and metaharness for agent work.Loom
