    Inspect the evidence trail

    Check that claims about the work point to concrete outputs rather than a fluent transcript.

    You can distinguish a claimed result from evidence that another person or tool can verify.

    Open this step →

    Choose whether to attempt implementation

    Treat the golden path's implementation wave and reference driver as optional experimental follow-ons: the published driven run does not reach completion today.
