Agent stack

One owner per layer

Six layers from applications down to model providers. A layer depends only on the layers below it. Recorded in the organization's architecture decisions 0096 to 0101, 2026-10-20.

Definitions

Each term, the layer it names, and the repositories that own it.
TermLayerWhat it doesOwned by
Model callL0One turn in, one turn out: messages and tools in; text, tool calls and usage out. Owns provider wires, credentials, routes and cost.llm (GitHub), inference, llm-gateway
HarnessL1The agent loop: turns, prompt assembly, tool round trips, compaction, session and transcript, budgets. Claude Code and Codex are vendor harnesses; tools holds the tool contracts.harness (GitHub), tools
Meta-harnessL2Starts any harness behind one event stream and one command set, allows, denies or rewrites each tool call, and records every session as trace-ir/1.metaharness (GitHub)
Agent runtimeL3 · governed runtimeLoom; loom-sdk is its library. Opens a case on a protocol and lets a model act only through the actions the case admits at that moment. Calls llm for its own short decisions and metaharness for agent work.Loom
Applicationabove L3An end-to-end use of the stack, built on loom-sdk. takt delivers stories and counts nothing done until a validator records the evidence; it manages agents and is not one.takt, swarm
Conductoroperator toolingCoordinates Claude Code sessions across the repositories of one organization: one session tracks every repository and starts one controller session per repository.conductor
Control planepausedA local workspace service: add repositories, set a goal, follow its plan, implementation assignments and verified merge receipts. Paused; it is not part of the stack above.control-plane
